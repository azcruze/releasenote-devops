About ReleaseNote

Automated software release management and changelog tracking.

What it does

ReleaseNote keeps a structured history of software releases: version, status, category, features, fixes, improvements and deployment notes.

It is also a working DevOps demonstration. A push to GitHub triggers a Jenkins pipeline that tests the code, deploys it to an Azure Linux virtual machine over SSH, restarts Gunicorn behind Nginx, and confirms the new build through the health endpoint.

Infrastructure is provisioned separately with Terraform.
